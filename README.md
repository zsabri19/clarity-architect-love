## Step 5: Content Backend (CMS)

The site must be backed by a real content backend so articles, frameworks, book chapters, and media assets are not hardcoded.

### Recommended CMS options (ask user if unsure)
- **Notion** (recommended if user already writes there) — pull pages via Notion API.
- **Sanity** — structured studio for articles, book chapters, frameworks, media.
- **Strapi / Directus** — cloud or self-hosted headless CMS.
- **Supabase + Storage** — PostgreSQL + file storage.
- **Airtable** — fast MVP for tabular content.

### Required content types
- **Article** — title, slug, summary, rich text/markdown body, hero image, category/tags, publish date, SEO title, SEO description, author, featured flag, related framework, related service, related book chapter, newsletter excerpt.
- **Book Chapter** — chapter number, title, slug, part, summary, key lesson, framework, body, SEO metadata, CTA.
- **Framework** — title, slug, short description, parameters, impact/metrics, body, download file, category, email-gated boolean, related article, related service, related book chapter.
- **Media Item** — title, outlet/platform, date, type (podcast / article / video / interview), link/embed, thumbnail, transcript snippet, related service.
- **Program** — title, description, status, how to engage, CTA, related content.
- **Newsletter Issue** — issue number, title, slug, date, body, excerpt, CTA.
- **Testimonial / Case Study** — quote, attribution, role/organization, related service, related framework.

### Sync strategy
- Content must update on the site when published or updated in the CMS.
- Prefer ISR or webhook-triggered rebuild.
- Fallback: graceful static content if CMS is unavailable.

### On-page SEO requirements
- Unique H1, title tag (≤60 chars), and meta description (≤155 chars) for every page.
- Semantic HTML with proper heading hierarchy (H1 → H2 → H3).
- Schema markup: Person, Organization, Book, Article, Course, ProfessionalService, Review, FAQPage where applicable.
- OpenGraph and Twitter Card tags for every page.
- Canonical URLs, sitemap.xml, robots.txt.
- Alt text for all images.
- Internal linking: every page links to 2–3 related pages/offers.
- Breadcrumbs where appropriate.
- Fast load times (Core Web Vitals passing).

### Content cluster strategy
Build clusters around each framework and book part:
- Pillar page: /frameworks/pyramid-framework
- Cluster articles:
  - /insights/pyramid-framework-adoption-case-study
